# AI-Powered Banking Customer Support Intelligence & Response Automation

An end-to-end, locally runnable portfolio project based on the attached project brief and the supplied dataset archive. It includes intent classification, response suggestions, confidence-based escalation, extractive conversation summaries, and support analytics in a Streamlit application.

## Important boundary

This is a teaching prototype, not a bank system. It does not connect to accounts, verify identity, send messages, execute transactions, or call an LLM. Response text is a draft for a human to review. Never enter real customer details, passwords, PINs, OTPs, or full payment-card numbers. Do not deploy for real customers without bank-approved privacy, security, validation, audit, and regulatory review.

## Dataset

The supplied ZIP contains `dataset/train.csv`, `dataset/test.csv`, and `dataset/train.xlsx`. The CSV files use two columns:

| Column | Meaning | Use |
|---|---|---|
| `text` | Example customer-support utterance | Model input |
| `category` | Intent label | Classification target |

The two supplied CSV splits are used as provided: training is split again into training and validation for model selection; `test.csv` is held out for final metrics. `train.xlsx` is retained as supplied but not required by the pipeline. The training script audits empty records, duplicate text, label counts, exact text overlap, and missing test labels. It does not invent or silently fill customer data. Dataset examples are short intent examples, not real customer conversation histories, so summarization is implemented as a deterministic extractive demonstration rather than trained or claimed to be a validated conversation summarizer.

## Step-by-step setup (Windows PowerShell)

Open PowerShell in this folder, then run:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
python train_models.py
streamlit run app.py
```

If `py` is unavailable, install Python 3.10 or newer from python.org, enable the PATH option, reopen PowerShell, and retry. If script activation is blocked, use `.\.venv\Scripts\python.exe -m pip install -r requirements.txt` and `.\.venv\Scripts\python.exe -m streamlit run app.py`.

For macOS/Linux, create `.venv` with `python3 -m venv .venv`, activate it with `source .venv/bin/activate`, then run the same pip, training, and Streamlit commands.

### Optional deep-learning comparison

TensorFlow is deliberately optional because it is larger and platform dependent. Install a compatible TensorFlow version for your Python/OS, then run:

```bash
python train_models.py --deep-learning
```

This writes separate BiLSTM metrics and model artifacts. It does not replace the baseline model used by the app. If TensorFlow cannot be installed on your machine, the full baseline app remains usable.

## What training does

1. Reads and validates `text` and `category` from both supplied CSV splits.
2. Normalizes whitespace, removes blank rows, and writes `artifacts/data_audit.json`.
3. Reserves 15% of the training split for stratified validation (seed 42).
4. Compares word/character TF-IDF Logistic Regression and calibrated Linear SVM using validation macro-F1.
5. Refits the validation winner on all of `train.csv`; leaves `test.csv` out of training.
6. Writes final accuracy, macro/weighted F1, macro precision/recall, top-3 accuracy, per-class report, predictions, and confidence values.
7. Saves the selected classifier, metadata, and artifacts for the app.

All reported performance values are generated by the run on your local copy. No score is promised in advance. Confidence scores are triage aids, not calibrated safety guarantees. Check the audit output for label coverage and overlap before interpreting test scores.

## Project requirements mapped to the implementation

| Brief requirement | Implementation |
|---|---|
| Data preparation and understanding | CSV schema checks, cleanup, split audit, class counts, overlap and duplicate report |
| Machine-learning baseline | Word + character TF-IDF Logistic Regression and calibrated Linear SVM |
| Deep-learning NLP | Optional BiLSTM training path; separate test metrics |
| Confidence and escalation | High/medium/low confidence routing plus conservative fraud cue escalation in `confidence_escalation.py` |
| Generative response | Safe response drafting interface in `generative_response.py`; controlled templates, no external service or fabricated account facts |
| Conversation intelligence | Extractive distinct-sentence summary; explicitly marked as unvalidated on this intent dataset |
| Business application | Streamlit tabs for triage, summary, analytics, and limitations |
| Evaluation | Accuracy, macro/weighted F1, macro precision/recall, top-3 accuracy, per-class report |
| Deployment | Local run commands; deployment is optional and should follow institution policy |

## Evaluation and demo checklist

1. Run training and retain `artifacts/data_audit.json` and `artifacts/test_metrics.json` for the report.
2. Compare the baseline validation scores in `artifacts/validation_metrics.csv`.
3. Review `artifacts/classification_report.csv` for weak or imbalanced intents.
4. Try clear, ambiguous, and simulated fraud-related messages in the app; confirm low-confidence/fraud cases route to a human.
5. Use synthetic conversation text in the summary tab and verify the generated extract is faithful.
6. Capture app screenshots and report real metrics from your run only. Do not describe the demo as production-ready.

## Troubleshooting

- **Missing CSV:** place `train.csv` and `test.csv` beside `train_models.py` or pass `--train PATH --test PATH`.
- **Missing artifacts:** run `python train_models.py` from this folder before starting Streamlit.
- **Memory/time:** the TF-IDF pipeline uses word and character n-grams; close memory-heavy applications and allow training to finish.
- **Unknown category at inference:** the model ranks learned intents only; low confidence should go to an agent.
- **Excel import issue:** the project reads CSV and does not need Excel or `train.xlsx` during normal execution.
